# À faire (Backlog contributeurs)

Ce dossier regroupe les chantiers identifiés qui dépassent le cadre actuel d'OpenGear (drivers noyau/système manquants, intégrations OS avancées ou réimplémentations lourdes) et qui pourront être repris lorsque le projet sera ouvert aux contributions.

## Sujets listés

- [hyperx-windows-apo-dts.md](./hyperx-windows-apo-dts.md) — Support des effets audio côté Windows (APO / DTS:X, EQ logiciel et traitements micro AINR / Limiter) pour les casques et micros HyperX sans DSP HID embarqué.
- [logitech-windows-apo.md](./logitech-windows-apo.md) — Support des traitements audio Windows côté pilote (Blue VO!CE 1/2 et DTS Headphone:X 2.0) pour les casques et micros Logitech G sans DSP HID équivalent.
