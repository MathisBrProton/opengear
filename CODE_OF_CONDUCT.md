# Code de conduite

OpenGear est un projet ouvert. Nous voulons qu'il soit un lieu accueillant pour tout le monde,
quels que soient le niveau, l'expérience, l'identité ou l'origine.

Ce projet suit le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

## En bref

- Sois respectueux et constructif, y compris quand on n'est pas d'accord.
- Accepte les critiques techniques : elles visent le code, pas la personne.
- Pas de harcèlement, d'insultes, de moqueries, de propos discriminatoires ni de publication
  d'informations privées d'autrui sans son accord.
- Pas de contenu sexualisé, ni de provocation.

## Signaler un problème

Pour signaler un comportement inapproprié, contacte directement le mainteneur via son profil
GitHub (<https://github.com/MathisBrProton>) en message privé. Ne publie pas le signalement en
issue ou en commentaire public.

Le mainteneur examine chaque signalement, garde la confidentialité sur son auteur, et peut
prendre les mesures suivantes : avertissement, retrait temporaire de la participation, ou
bannissement du projet.
